# Homebrew Tap

Custom Homebrew formulae.

## Installation

```bash
brew tap ianzepp/tap
```

## Formulae

### abbot

Persistent AI background daemon.

```bash
brew install ianzepp/tap/abbot
```

After installation:

```bash
# Show system info
abbot info

# Install as system service
abbot service install
abbot service start

# Or run in foreground
abbot run
```
